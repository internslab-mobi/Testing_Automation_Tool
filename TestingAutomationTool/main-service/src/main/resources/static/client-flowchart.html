STAGE 04

Defect State Machine & Real-Time Collaboration

Auto-Generated Bug IDs, History Auditing, Bug Chat & RCA
🐛
QA Tester
9. Defect Auto-Creation
Failed test auto-logs defect. System generates ID (BUG-FEATURE-001), logs history, and fires email alert to assigned developer.
POST /bugs Inspect ➔
💬
Developer
10. Bug Chat & Investigation
Developer sets status to IN_PROGRESS. Discusses details via real-time defect comments and uploads stack traces/evidence.
POST /bugs/{id}/comments Inspect ➔
🛠️
Developer
11. Fix Submission & RCA
Developer submits code fix with mandatory Root Cause Analysis (RCA) comments. State transitions to RESOLVED ➔ FIXED.
PATCH /bugs/{id} Inspect ➔
✅
QA Tester
12. Verification & Closure
QA verifies fix in new build. If verified ➔ CLOSED. If defect persists ➔ REOPENED back to developer queue.
PATCH /bugs/{id} Inspect ➔
